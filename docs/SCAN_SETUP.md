# Scan — ছবি তুলে বিল / তালিকা ঢোকানো: সেটআপ (মালিকের জন্য, ফোনে)

Scan মানে: বিল, পণ্যের তালিকা, খরচের রসিদ বা রিপোর্টের **ছবি তোলা** -> সিস্টেম একটা **খসড়া (draft)** বানায় -> আপনি ছবির পাশে দেখে প্রতিটি ঘর ঠিক করেন -> **Confirm** চাপলে তবেই বিদ্যমান save ফাংশন দিয়ে ঢোকে (ক্রয় বিল: `save_purchase`, খরচ: `quick_expense_add`, নতুন পণ্য: `item_new`, দাম বদল: `item_apply`)।
ছবি নিজে থেকে কিছুই ঢোকায় না। "অটো-কনফার্ম" বলে কিছু নেই, বানানোও হয়নি। দুইবার Confirm চাপলেও একবারই ঢোকে। একই সাপ্লায়ার + বিল নম্বর + মোট আগে থাকলে সতর্ক করে, আপনি দেখে নিশ্চিত না করলে আটকায়।

## ১. কোনটা তৈরি, কোনটা আপনাকে করতে হবে, কোনটা যাচাই হয়নি

| বিষয় | অবস্থা |
|---|---|

| ফোনের পাতা `#/scan` (`web/scan.js`): ক্যামেরা / গ্যালারি, ছোট করে আপলোড, ছবির পাশে এডিট, হলুদ ঘর, মিল বাছা, Confirm / Reject, অফলাইন কিউ | **তৈরি + নকল (mock) সার্ভারে পরীক্ষিত** (`tests/web/scan_test.js`, `scan_pw_test.js`)। আসল Supabase-এ আসল ফোনে চালানো হয়নি |
| `manual` পদ্ধতি (ছবির পাশে নিজে লেখা) | তৈরি, সবসময় চলে, কিছু সেট করতে হয় না |
| `browser_ocr` (ফোনেই বিনামূল্যে পড়া, tesseract.js 5.1.1) | কোড তৈরি; **আসল ছবিতে পাঠ-মান যাচাই হয়নি**। বাংলা ও হাতের লেখায় দুর্বল (অ্যাপও তা বলে) |
| `ai_vision` (AI দিয়ে পড়া): `supabase/functions/scan-extract/index.ts` | **শুধু সোর্স** — deploy হয়নি, AI API-র বিপক্ষে চালানো হয়নি। আপনাকে চাবি ও deploy করতে হবে (নিচে ধাপ ৫) |
| আসল Supabase-এ phase90 paste, switch চালু, grant দেওয়া | **আপনার করণীয়** |

## ২. SQL বসানো (ফোনে, একবার; দুইবার করলেও ক্ষতি নেই)
1. আগের সব phase (phase8 … phase84) আগেই বসানো থাকতে হবে। না থাকলে phase90 নিজেই থামে ও লেখে "phase90 needs the earlier phases pasted first".
2. ফোনের ব্রাউজারে Supabase প্রজেক্ট খুলুন -> **SQL Editor** -> New query।
3. `supabase/phase90.sql`-এর পুরো লেখা কপি করে paste করুন -> **Run**। "Success" এলে হয়ে গেছে।
4. ছবির bucket `photos` আগে থেকেই **private**; phase90 তা private-ই রাখে। কোনো ছবির public লিংক বানানো হয় না, অ্যাপ ১০ মিনিটের signed লিংকে দেখায়।

## ৩. চালু করা (Switchboard, ফোনে)
- **Switchboard** -> `scan_enabled` = চালু। (ডিফল্ট বন্ধ।)
- `scan_engine`: `manual` (ডিফল্ট) / `browser_ocr` / `ai_vision`। প্রথমে `manual` দিয়ে শুরু করুন।
- `scan_min_confidence` (ডিফল্ট 0.6): পাঠ-যন্ত্র এর নিচে নিশ্চিত হলে ঘরটি **হলুদ** হয়। এটি শুধু সতর্কতা, Confirm আটকায় না।
- **Staff -> অনুমতি (grants):**
  - `scan_upload` = ছবি তুলে খসড়া বানাতে পারবে (ডিফল্ট: purchasing, storekeeper, showroom_manager, management)।
  - `scan_confirm` = Confirm / Reject করতে পারবে (ডিফল্ট: management; মালিক সবসময় পারেন)। Confirm করলে যা ঢুকবে তার জন্য সেই ব্যক্তির আগের অনুমতিও লাগে (যেমন ক্রয় বিলে `purchase_entry`, খরচে ১১-১ enter)।
  - ক্রয় বিলের দাম (cost) শুধু মালিক, যিনি ছবি তুলেছেন, আর cost-দেখার অধিকারীরা দেখতে পান। অন্যরা বিলের সংখ্যা দেখেন না।

## ৪. `browser_ocr` (ফোনেই, বিনামূল্যে, কোনো চাবি লাগে না)
- `scan_engine` = `browser_ocr`। প্রথমবার ছবি পড়ার সময় ফোন ইন্টারনেট থেকে OCR লাইব্রেরি নামায় (jsdelivr CDN-এ `tesseract.js@5.1.1`, সংস্করণ বাঁধা) আর ভাষার ডেটা। "বাংলাও পড়ুন" টিক দিলে বড় ডাউনলোড।
- ইন্টারনেট ছাড়া OCR চলবে না (ছবি ফোনে জমা থাকবে, পরে যাবে; পড়া তখন নিজে লিখুন)।
- ছাপা ইংরেজি বিলে মোটামুটি, **বাংলা ও হাতের লেখায় দুর্বল**: প্রতিটি ঘর নিজে মিলিয়ে নিন। এটি **যাচাই হয়নি**: আপনার আসল বিলের ছবিতে কেমন পড়ে তা আপনাকেই দেখতে হবে।

## ৫. `ai_vision` (AI): কম্পিউটারওয়ালা সাহায্যকারী বা Supabase dashboard লাগতে পারে
1. **AI অ্যাকাউন্ট ও চাবি:** Anthropic Console-এ অ্যাকাউন্ট খুলে API key বানান; **খরচের সীমা (spending limit) বসান**। একটি ছবির খরচ মডেল ও ছবির আকারের উপর নির্ভর করে: দাম মডেলের দামের তালিকা থেকে নিজে দেখুন (এখানে লেখা সংখ্যা **যাচাই হয়নি**)।
2. **চাবি কখনো চ্যাটে, ছবিতে বা repo-তে দেবেন না।** শুধু Supabase-এর secret-এ রাখুন: Dashboard -> Edge Functions -> **Secrets** (বা কম্পিউটার থেকে `supabase secrets set ANTHROPIC_API_KEY=...`)। দুটি secret লাগে:
   - `ANTHROPIC_API_KEY` = আপনার চাবি
   - `SCAN_AI_MODEL` = যে ছবি-পড়তে-পারা (vision) মডেল ব্যবহার করবেন তার নাম (Anthropic-এর বর্তমান তালিকা থেকে বেছে নিন; এখানে ইচ্ছে করেই নাম বসানো নেই)
3. **Deploy:** Dashboard -> Edge Functions -> New function -> নাম `scan-extract` -> `supabase/functions/scan-extract/index.ts`-এর লেখা paste -> Deploy। (ফোনের ব্রাউজারে "Desktop site" দিয়ে হতে পারে — **যাচাই হয়নি**; না হলে কম্পিউটারওয়ালা কারও `supabase functions deploy scan-extract`।) JWT যাচাই **চালু** রাখুন (ডিফল্ট): শুধু লগইন করা স্টাফ ডাকতে পারবে। `--no-verify-jwt` দেবেন না।
4. `scan_engine` = `ai_vision`।
5. ফাংশনটি যা করে: স্টাফের নিজের লগইন দিয়ে ছবি নামায় (private bucket), AI-কে এক বাঁধা ফরম্যাটে (tool) উত্তর দিতে বলে, উত্তর সার্ভারে আবার কড়া যাচাই করে, তারপর ডেটাবেস আরেকবার যাচাই করে **শুধু খসড়া** বানায়। AI কোনো পণ্য বা সাপ্লায়ার বাছতে পারে না (id ও সিদ্ধান্ত ফেলে দেওয়া হয়)। `service_role` চাবি কোথাও লাগে না।
6. AI ভুল করে — হলুদ ঘর ও মিলানো আপনাকেই দেখতে হবে। ফাংশন বন্ধ বা ব্যর্থ হলে খসড়া খালি থাকে ও আপনি নিজে লেখেন (কিছু হারায় না)।

## ৬. কীভাবে ব্যবহার করবেন (ফোনে)
1. মেনু -> **ছবি থেকে এন্ট্রি (Scan)**। ধরন বাছুন (ক্রয় বিল / পণ্যের তালিকা / খরচের রসিদ / অন্য কাগজ), জায়গা বাছুন, **ক্যামেরায় ছবি তুলুন** বা গ্যালারি থেকে নিন। ছবি ফোনেই ছোট করা হয় (প্রায় ৭০০ KB-এর নিচে)।
2. ছবির পাশে (ফোনে ছবির নিচে) লাইনগুলো দেখুন ও ঠিক করুন। **হলুদ ঘর** = পাঠক নিশ্চিত ছিল না ও আপনি বদলাননি।
3. প্রতিটি লাইনের জন্য **আপনি** সিদ্ধান্ত দিন: এখনকার আইটেমের সাথে মেলান (মিলতে পারে এমন নাম দেখায়, ট্যাপ করে বাছুন) / নতুন আইটেম বানান / শুধু লেখা (স্টক নয়) / বাদ দিন। কিছু নিজে থেকে মেলানো বা বানানো হয় না। সাপ্লায়ারও বাছুন বা "নতুন সাপ্লায়ার" বলে চিহ্নিত করুন।
4. **দেখা শেষ — Confirm**। সারাংশ দেখে Confirm চাপুন। ক্রয় বিল ডিফল্টে **খসড়া ক্রয় বিল** হয়; "বিলটি পোস্টও করুন" টিক দিলে স্টকেও যায়।
5. ভুল ছবি হলে **Reject** (কারণসহ); কিছু মোছা হয় না, ইতিহাস থাকে।
6. ইন্টারনেট না থাকলে: ছবি ফোনে জমা থাকে ("পাঠানো বাকি ছবি"), নেট এলে নিজে থেকে বা "এখন পাঠান" চাপলে যায়। একই ছবি দুইবার গেলেও একটাই খসড়া হয়। খসড়া এডিট ও Confirm-এ ইন্টারনেট লাগে।

## ৭. সীমা ও সাবধানতা (সৎভাবে)
- ছবিতে ব্যক্তিগত তথ্য থাকতে পারে: bucket private, শুধু ছবির মালিক, মালিক আর ঐ জায়গার `scan_confirm` অধিকারী দেখতে পান। যাদের অধিকার নেই তারা সরাসরি ফাইলের নাম জেনেও পড়তে পারে না (storage নীতি)।
- আপলোড হয়ে খসড়া বানানো না গেলে (নেট কেটে গেলে) ছবি bucket-এ পড়ে থাকতে পারে; সাফ করার স্ক্রিপ্ট বানানো হয়নি।
- ছবিগুলো `tools/backup_photos.py`-র ব্যাকআপে ঢোকে কি না — **যাচাই হয়নি**।
- খরচের `head` একটি ইংরেজি ছোট কোড হতে হয় (যেমন `transport`); বাংলা লিখলে সেটি বাদ পড়ে, আপনি ইংরেজিতে লিখে দেবেন।
- খরচ Confirm-এ `quick_expense_add`-এর নিয়ম বহাল: আজ বা ৭ দিনের মধ্যের তারিখ (মালিক ছাড়া), লক হওয়া সময়ে নয়।
- নতুন পণ্য বানাতে `item_new`-র নিয়ম বহাল; অনুমোদন-সাপেক্ষ হলে Confirm "item_needs_approval" বলে থামে (কিছু ঢোকে না)।
