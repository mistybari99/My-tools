# পড়ে বোঝা
* acct_post_pending keeps its manage check for people; the scheduler path is `auth.uid() is null` + a transaction-local setting set only inside acct_autopost_tick (which anon cannot execute and signed-in people can only run as owner).
* Turning a switch on posts the backlog back to the accounting start (or acct_stock_moves_from) at the original dates; dates inside a closed period are held (locked) except for the owner. Use the from-date rule if that is not wanted.
* acct_stock_opening must stay off when the stock is already inside the opening balance (acct_opening), or it counts twice (hint text says so).
* transit loss "receiver" books the loss at the receiving place, so the clearing account shows sender +V / receiver -V until the owner settles it; "sender" is the alternative.
* The purchase-variance lines use the purchase item-type keys (_acct_buy_key); an item type that is stock-tracked but booked to purch_consumable on purchase is left out of the variance (same limit as inventory_vs_gl).
* Old files phase40/ALL_NEW10 re-pasted after phase85 would re-create the 7-argument acct_journal_post (ambiguous overload); they must not be re-pasted.
