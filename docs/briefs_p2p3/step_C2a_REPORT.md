## What was built (per brief point)
- **C2ক.1 `cost_sources`** (`phase75.sql:45`): code `src-N`, cost type (বিদ্যুৎ / গ্যাস / ঘর ভাড়া / লাইসেন্স ও ফি / যন্ত্র মেরামত / পানি / ইন্টারনেট / ☐ অন্য - `cost_source_types`, owner adds types with `cost_source_type_add`, each type maps to the pool type its FACTORY share lands in: electricity->electricity, gas->gas, rent->factory_rent, licence->licence_fee, repair->machine_repair, water/internet/other->other), provider / meter / contract no (may be blank), covered locations (`cost_source_locs`), kind separate | shared, effective date, active, frequency (monthly / yearly / irregular - only used for the 'বিল বাকি' marker). Several sources per type allowed. After a bill exists the type / kind / places cannot change (open a new source).
- **C2ক.2 `cost_source_bills`**: period month or year, amount, payment mode, bill no, bill date, client_id (idempotent), one-off flag ('একবারের খরচ'), 10-2 reference number. A yearly bill goes to the pool as ONE row of period year and the phase74 code reads it /12 per covered month (checked: 12000 -> 1000 a month, null before and after the 12 months). Duplicate bill number on a source refused. **10-2 duplicate guard**: an approved/submitted 10-2 of a covered place, same month, head (repair for electricity/gas/water/internet/machine repair, other otherwise) and the same amount -> yellow flag + `cost_bill_dup_voucher` exception; the owner can say "this is a different cost" with a reason (kept in `dup_ack_note`).
- **C2ক.3 allocation rules** (`cost_source_rules` + `cost_source_rule_shares`): sub-meter reading (typed per bill) | fixed percent | floor area (sq ft) | headcount | output kg (AUTOMATIC from the month's done production runs of kg items, voided runs ignored - nothing typed) | whole bill to one location | other = hand-typed amounts per bill. Every share is (location, destination) with destination factory / showroom / admin; one bill can split over several destinations (checked: 400.40 factory + 100.10 admin + 500.50 showroom = 1001.00, the last share takes the rounding). **Fixed percent: if every value is typed they must total 100 or saving is refused (`percent_not_100`)**; a rule with a blank value saves only as an incomplete draft that cannot be approved. Hand-typed amounts above the bill are refused (`shares_exceed_bill`, nothing left behind); below the bill the rest is an 'অভাগিত' row with a yellow flag. A shared bill with no approved rule, a missing meter reading or no output is stored whole as an 'অভাগিত' row (flag no_rule / meter_missing / no_output). Separate sources have no allocation step: the whole bill goes to its destination (one share, 100%).
- **Effective dates**: a rule applies to bills whose month is on/after its effective date; the allocation of a bill is frozen when made and stored (`cost_bill_shares` with `rule_id`). Approving a new or back-dated rule never changes a fully allocated bill (checked); only bills still waiting for a split are allocated. Old rules stay approved with their own date (same-date replacement marks the old one superseded, kept). Audit on every row.
- **C2ক.4 flows**: factory shares are pushed BY THEMSELVES into `factory_cost_pools` (source `allocated`, ref `bill:<id>:<loc>`, type mapped, month, month/year kind, one-off flag) and are replaced when the bill is allocated again or retired when it is voided - the phase74 pool-rate code reads them with no change (checked end to end: a new site's electricity bill gives rate 4.5 per kg and +45 on a 10 kg batch). Showroom and admin shares stay in `cost_bill_shares` and are read by `branch_overhead(loc, from, to)` (yearly fees /12) for the branch P&L. **'বিল বাকি'**: `cost_sources_status(month)` lists monthly/yearly sources with no bill for the month (a covering yearly bill counts); irregular sources never; the pool figure of such a month stays null - never an average. The manual `pool_set` now warns (`pool_double_entry`) when a bill already feeds the same pool.
- **C2ক.5 blank start**: no source, rule, bill, rate, percentage, meter or area is seeded. List 'ভাগ নির্ধারিত নয়' = shared sources with no approved complete rule in force for the month (reason no_rule / draft / incomplete).
- **C2ক.6**: pickers read `locations` (`cost_pick_locations`, and the web page); verified with a location created after everything else: a source, a rule, a bill and the pool row for it work with no code change.
- **C2ক.7**: view and edit = cost right (`_recipe_cost_ok`), RLS on all 8 tables (+ place scoping for people who do not see all places); entering sources / bills / rules needs grant `cost_bill_entry`; approving a rule needs a DIFFERENT person with grant `cost_rule_approve` (or the owner for what he did not enter); the entry person is refused (`self_approve_refused`) even if he holds both grants, unless the owner switches `cost_rule_self_approve` ON (default off). Every write has a client_id where it creates something and an audit row.
- **Web** `web/costsources.js` (`#/costsources`): status (four lists + duplicate ack), sources (place checkboxes read from the locations list, "☐ অন্য: নতুন ধরন"), rules (grid of place x destination, blank values allowed, live percent total, approve, refusal messages), bills (readings boxes only when the rule needs them, one-off, void with reason, allocate again).

- Output-kg allocation counts only kg-based items; a location producing pieces gets `no_output`.
- The warning exception for an unallocated bill is attached to the first covered location of the source.

## Mismatches with the printed forms (NOT changed, listed)
1. **10-2** (`web/forms.js:27-47`) has head / paid to / receipt / amount per line and NO bill-number column: "the bill has the detail, 10-2 only a bill number" can only be done by writing the number into "paid to" (free text). The guard therefore matches on place + month + head + amount, not on a number.
2. **10-2 heads** are coarse: `repair` = "মেরামত / ইউটিলিটি" covers electricity, gas, water, internet AND repairs; rent / licence have no head (they fall under `other`). The mapping (repair / other) is a convention of the guard, not the form.
3. 10-2 is the petty-cash (imprest) voucher; large utility or rent bills normally are not paid from it, so the guard rarely fires. The yearly licence is a bill here and an annual figure in the pool; the paper has no place for it.
4. **02-2 payroll / labour** is not a cost source (it is not a bill); the labour pool is still typed by hand (step C).
