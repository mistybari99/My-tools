## প্যাকেজিং ফেরত — প্রস্তাব (মালিকের সিদ্ধান্ত; কিছু বদলানো হয়নি)
বর্তমান: `packaging_consume_on = sale` হলে বিক্রি তৈরির সময় `_sale_packaging_out` প্যাকেজিং স্টক কাটে (`sale_pack`); void হলে `_sale_packaging_void` ফেরত দেয়। কিন্তু `sale_return` শুধু `sale_out` সারি ফেরত দেয়, `sale_pack` নয় — তাই পণ্য ফেরত এলে প্যাকেজিং স্টক ফেরত আসে না (ফেরত আসা পণ্য সাধারণত নতুন প্যাকেজিং-এ নয়, কিন্তু রেকর্ড অমিল থেকে যায়)।
- বিকল্প ক: আজকের মতোই রাখা (ফেরত = প্যাকেজিং নষ্ট ধরা), রিপোর্টে ডকুমেন্ট করা। ঝুঁকি: প্যাকেজিং স্টক সামান্য কম দেখায়।
- বিকল্প খ: `sale_return`-এ সেটিং `packaging_return_mode = none | restore | wastage` — `restore` = অনুপাতে `sale_pack` ফেরত (reverses_id দিয়ে), `wastage` = কারণসহ নষ্ট হিসাবে লেখা (স্টক কমেই থাকে, কিন্তু রেকর্ড হয়)। ডিফল্ট none।
- বিকল্প গ: ফেরতের পর্দায় প্রতিবার জিজ্ঞাসা ("প্যাকেজিং ফেরত এসেছে?")।
- সুপারিশ: খ, ডিফল্ট `none`, `wastage` মোড আগে (নিরাপদ, স্টক বাড়ায় না)। সিদ্ধান্ত পেলে আলাদা ধাপে করা হবে।
