# docs/ index

English index of every folder under `docs/`, and of the files at the top level. Links are relative to this file. The Bangla owner guides are in `guide/`.

## Folders

- [guide/](guide/OWNER_GUIDE.md) - owner guides in Bangla: new features from phase 72 to 103, phone-only steps, recommended settings, safe rollout order, 30-minute UAT checklist.
- [backend/](backend/README.md) - backend and developer documentation in English: architecture, data flow, security model, developer runbook, troubleshooting.
- [backend/catalogue/](backend/catalogue/CATALOGUE_README.md) - generated catalogues of tables, functions, routes, grants and rules, and how to regenerate them.
- [i18n/](i18n/BANGLA_REVIEW.md) - Bangla and Bangla-English proofreading of all new user-visible strings (Markdown and CSV).
- [briefs/](briefs/00_RULES.md) - common rules for every module agent, and the module briefs A, B1, B2, C, D, E, F and G.
- [briefs_p2p3/](briefs_p2p3/INDEX.md) - P2 and P3 gap work and step reports; [INDEX.md](briefs_p2p3/INDEX.md) lists every report.
- [inputs/](inputs/Build-commands-functions-only.md) - source inputs: item dictionary spreadsheet, form kit JavaScript, build commands, dry-run preview JSON, seed item mapping CSV.
- [plan_v2/](plan_v2/README.md) - planning only, no code: business, functions, owner answers, reports hub and UI plan.
- [regs/](regs/accounts.md) - module registration notes for the lead to apply (accounts, assistant, attendance, customers, employees, notifications, owner home, partners).

There is no `handovers/` folder. The handover notes are the `HANDOVER*.md` files listed below.
