# Assistant access (phase62, #30)
Before: `_assistant_ok()` (phase47) allowed the owner, anyone with `head_management`, anyone with `assistant_use`, and any role named in the rule `assistant_roles` (`*` = everyone). The nav entry (`ia.js` rec 'assistant', group reports) mirrored owner / head_management / assistant_use.
Now (phase62, tag bos62): the owner, or a person holding the grant `assistant_use` (per person via the grants screen, or per role via role grants, at any place). Nobody else; head_management and the `assistant_roles` rule no longer open it. The server refuses (`not allowed` / `assistant_me().allowed=false, reason no_right`) for everyone else, on every assistant function (assistant_me, assistant_log, notes, usage).
Owner grants / revokes in the existing screen (#/delegation, grant "Use the business assistant"); #/integrations -> Assistant tab lists the current holders (`assistant_access_list`, owner only). Switch `assistant_on` still turns it off for everybody.
