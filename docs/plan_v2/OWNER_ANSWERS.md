# Owner answers (build go-ahead given) — these override open questions in the three plans
General rule: EVERYTHING is an option in Settings: editable, add/remove/increase/decrease; no hard-coded business numbers.
1. Conversion settings (kg/piece/box/pack etc.) are editable per item and as global unit sets.
2. Owner can grant ANY person access to cost, profit/loss, reports, salary, export (per-grant, per-location, editable, with emergency path). Not owner-only by force.
3. Fiscal year start + period (month/week/day boundaries) are settings; editable; reports follow it.
4. Barcode: camera scan and device (hardware scanner / typed) are SEPARATE options (per device/user setting).
5. Permission-less modules: BOTH modes as a setting — lock-card or hidden; plus lock/hide per module per role.
6. Favourites / most-used / pinned-in-front for every work (per user, plus owner-set defaults per role). 
7. Business vs Accounting toggle: logical choice — Business = sales/stock/ops; Accounting = books, dues, payables, P&L, cash.
8. Core base must not break: all changes additive/idempotent/rules default off-or-warn; existing data untouched; test before ship.
9. One place (central inbox/filter hub) to see everything across forms/locations, AND owner can enter from anywhere (central quick-entry for any location/form).
10. Invoice template designer + settings: header, footer, logo, VAT on/off, fields on/off; paper sizes: common/A4 printer, thermal (58/80mm), invoice, barcode label. Print sizes editable.
11. Discount: BOTH fixed amount (cash) and percentage; both selectable at POS, limits per rule.
12. Brand/showroom-wise reports and also combined total; switchable everywhere.
13. Shelf-life varies by season/time for the same sweet: shelf-life table with season/date-range rules per item/category, fully editable.
14. Stock tracking, pilot items, costing method etc.: decided by logic, all switchable in settings (tracked flag per item; costing method setting).
15. Reports: build the P1 set (30) first; all 65 over time; every report's access grantable.
